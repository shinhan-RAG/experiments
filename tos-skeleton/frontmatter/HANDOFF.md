## 0. 용어 (확정 — 이 순서로 이해할 것)

```
택소노미 (L1~L4)      : 컬렉션 찾기 층 (미구현, 설계만)
시멘틱 레이어          : 컬렉션 안에서 문서를 선택하는 색인 층
  = Index (JSON)      : 그 실체. LLM Wiki의 index.md 역할
                        (collection_index.json, schema v3 — "컬렉션 frontmatter"라는 구 명칭 폐기)
frontmatter           : 문서 1건별 요약정보 (유형별 뼈대에서 규칙 추출한 key-value)
                        Index 안의 문서 엔트리 = 얇은 frontmatter, 별도 풍부판(원 ONE) 존재
시멘틱 태그·메타데이터  : 문서 안(엘리먼트·청크) 층 — 회의 정의 따름, 이 트랙 범위 밖
```

- LLM Wiki 원조 동작: index 읽고 후보 → 각 문서 frontmatter로 확정 → 본문. 우리 구조는 그 확장.
- **원칙: 원장 하나·뷰 여러 개** — 검색 방식(파일/벡터)별 차이는 필드 분리가 아니라 뷰 렌더링으로.
  (받은 지적 "방식별로 필드가 달라야 하지 않나"에 대한 대응 논리 — §6 참고)

## 3. 고정 벤치마크와 최종 결과 (v2, 2026-08-04)

문제지 688문항 고정: **신원 582**(파일명 사실 기반, 2회 재현 확인) + **내용 69**(자연어 질문
= haiku 생성, 정답 = 본문 앵커 합집합 rg 검증) + **혼합 37**(내용+최신 제약, 정답 중앙 2건).
채점: BM25, 정답=집합, hit@1/5.

| 유형 | 파일명 | Index | fm | Index+fm |
|---|---|---|---|---|
| 신원 (582) | .53/.82 | **.72/.91** | .32/.58 | .40/.63 ⚠ |
| 내용 (69) | .03/.06 | .03/.06 | **.06/.10** | .06/.10 |
| 혼합 (37) | .00/.03 | .08/.08 | .00/.08 | **.11/.14** |

**핵심 결론 4개:**
1. **각 색인은 자기 과목에서만 이긴다** — Index=신원(McNemar p=2.9e-21, ablation: 정규화 title +7%p),
   fm=내용. 대각선 구조가 계층 분담의 실증.
2. **⚠ 단순 결합(표현 연결)은 신원 과목을 파괴** (.72→.40) — fm 텍스트가 신원 토큰 희석.
   결합은 concat이 아니라 **질의 유형 라우팅 또는 2홉(Index→fm)**이어야 함.
3. **자연어 내용 질의에서 단어 매칭(BM25)은 전멸** (최고 .10) — 어휘 간극.
   이 구간이 벡터 서치·에이전틱·LLM의 존재 이유 (원 ONE의 LLM 라우터 결과와 일치).
4. 혼합 질의(실사용 근사)는 결합만 생존 — 2층 아키텍처 필요성의 직접 증거.

**선행 검증 (참고)**: 에이전틱 문서찾기 A/B — 에이전트는 파일명만으로도 상당 부분 해석
(BM25 격차의 절반 이상을 메움), Index 제공 시 +10%p·홉 2배 (886KB 통짜 색인의 비용
→ 계층화 필요). 원(ONE) 트랙: 게이트1 100%, 진짜 QA셋 +7.3%p, 요약은 문서 특정에 역효과.

## 6. 받은 지적 및 대응 (요지)

- **"검색 방식별로 frontmatter 필드가 달라야 하지 않나"** → 뷰 레벨에서 옳음(실증: 요약문은
  파일서치에 해악·벡터 임베딩에 필수, 정규화 토큰은 그 반대). 대응: 원장 하나 + 필드별
  serves 태그(파일서치뷰/벡터필터/벡터임베딩) + 뷰 렌더링. 원장 추가분은 summary·보안 3필드뿐.
  **벡터 서치도 LLM 생성 없이 가능** (필터=규칙 필드, 임베딩 텍스트=규칙 필드 조합).
- **"컬렉션은 전체 1개다"** → 반영 (상품 폴더≠컬렉션, Index는 컬렉션 1개의 색인)
- **"결과가 널뛴다, 문제지를 고정하라"** → 통합 벤치마크로 해소 (§3)
- 적재 설계 회의 지적(운영 프로세스·DB 직접 업데이트 금지·현업 눈높이·8/7 마감)은 별도 유효
