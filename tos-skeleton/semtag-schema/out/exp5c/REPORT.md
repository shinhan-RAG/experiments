## 관측·제약 (dev 튜닝 결과이며, 이 문서·이 QA셋 한정)

- 최선 조합은 K20_max: R@5 +4건(회귀 0), ΔR@5 CI가 0을 제외. 단 ΔMRR CI는 0 포함 — 1위권 개선이 아니라 5위 경계 통과가 주효과.
- 모든 조합에서 R@10은 A0(.4792) 대비 하락(.3229~.4479). 그룹핑이 상위 그룹의 형제 element를 top10에 끌어올리며 다른 gold를 밀어내는 비용이 존재. R@5 개선과 R@10 손실의 교환이며, 후속 단계(reader)가 top10을 쓰면 순손실일 수 있음.
- sum은 그룹 크기에 비례해 대형 조(표 다수 포함)를 과대평가 → 일관 악화. max2도 회귀 다수.
- 혼동형(같은 조 그룹 내 형제에 밀린 유형)은 이 방식으로 구제 불가 — 그룹 내부 순서가 element 점수 그대로이므로 설계상 순위 불변.
- dev 96 단일 문서 소표본. test 미평가이므로 일반화 주장 불가.
