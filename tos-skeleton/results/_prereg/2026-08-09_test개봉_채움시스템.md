## 3. 사전 등록 — 지표·가설·게이트

### 3-1. 주 지표 — **`R@10`**

병기: `R@5` · `R@20` · `R@1` · `MRR@10`. **판정은 `R@10`으로만 한다.**

### 3-2. 주 가설 — **하나**

| | 대조 | 지표 |
|---|---|---|
| **H1** | **채움 시스템** vs **전역 RRF k=5 top10** | `test` `R@10` |

**짝지은 McNemar 정확검정, 양측, α = 0.05. 단일 검정.**
그 외 전부 기술통계 + Wilson CI. **`p`값 금지.**

### 3-3. ★ 사전 예측 — 숫자를 먼저 박는다

개발셋 효과 크기 `Δ/n`: 확정 210 `+.119` · 비순환 155 `+.148`.
**test에서의 예측 효과: `+.10` 이상** (보수적으로 개발셋 하한을 씀).

| 게이트 | 조건 |
|---|---|
| **0** | **채움 `R@10` > 전역 RRF `R@10`** — 방향 일치 |
| **1** | **순 Δ / n ≥ `+.10`** — 개발셋 효과의 재현 |
| **2** | **McNemar `p < .05`** |
| **3** | **널 초과** — 에이전트 5칸을 무작위 element로 치환한 20시드 널을 넘을 것 |

| 결과 | 판정 |
|---|---|
| **0·1·2·3 모두** | **확증.** 이 시스템을 출하한다 |
| 0·2·3 통과, 1 미달 (`+.05 ~ +.10`) | **부분 확증.** 효과는 실재하나 개발셋에서 과대추정됐다 |
| **0 또는 2 미달** | **개발셋 결과는 과적합이었다.** 채움 시스템 철회 |

### 3-4. 검정력

개발셋 불일치쌍 `D`: 확정 210에서 60. test `n`이 비슷하면 `D≈45`, `Δ/n=+.10`이면 순 Δ ≈ 15.
`D=45`에서 유의 최소 순 Δ = **+14**. **검정력은 충분하다.**

`test`의 gold 보유 행 수가 **100 미만이면 검정력 부족을 보고에 명기하라.**

### 3-5. 널 — **필수**

| 널 | 산출 |
|---|---|
| **무작위 5 + RRF 채움** (20시드) | 에이전트 자리를 무작위 element 5개로. LLM 0회 |
| **RRF만 top10** | H1의 대조 그 자체 |
