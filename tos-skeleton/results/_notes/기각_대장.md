```
L*가 보상하는 것 :  이미 실패한 문항이 덜 실패하는 것
```

**`R@K`가 맞는 것을 재고 있었다.** `L*`의 정보량이 20배 많았던 것은

**대장 사용 규칙 (§9 초판의 규칙을 대체)**:
`L*` 단독 유의는 **채택 근거가 되지 않는다.**
`L*`를 쓰려면 **중앙값 변화와 상위 K 예산 변화를 반드시 병기**하고, 둘 중 하나라도 개선이 없으면 기각한다.

### 10-b. 폐기 사유가 **아닌** 것

| | 왜 아닌가 |
|---|---|

### 10-c. `φ`를 독립성 지표로 쓰지 마라

```
φ = (a − b) · √( π(1−π) / p(1−p) )      a=P(라우터적중|기저적중), b=P(라우터적중|기저실패)
```

**조건부 정확도 격차의 재척도값이다. 독립성 지표가 아니다.** 항등식이므로 데이터를 다시 뽑아도 같다.

### 10-d. ★ 확증 하한 — 이 프로그램이 한 번도 정의하지 않은 것

확정 210 · 짝지은 McNemar 정확검정:

| 악화 `c` | `p<.05` 최소 개선 `b` | **순 Δ** | Holm(50칸, α=.001) | **순 Δ** |
|---|---|---|---|---|
| 0 | 6 | **+6** | 11 | **+11** |
| 3 | 12 | +9 | 19 | +16 |
| **5** | **15** | **+10** | **23** | **+18** |
| 10 | 23 | +13 | 32 | +22 |

**프로그램 전체 최고치는 `+9`(악화 8 → 하한 +12).**

> **"27칸 전부 음수"와 "최고 +9"는 이 무대에서 통계적으로 같은 문장이다.**
> **23라운드가 전부 무정보였다.**

**새 규칙**: 어떤 개입이든 **착수 전에 예상 악화 `c`를 추정하고 그에 대응하는 확증 하한을 기록한다.**
하한에 못 미치는 개입은 **측정하지 않는다.**

### 10-e. 재현되지 않은 것 — 미결로 남긴다

| 실패 126 분해 | 검토가 재현 실패 (특약 다름 47 → **54 또는 33**). 정의 미기록 |

**위 수치를 근거로 인용하지 마라.**

## §11. 널 규율 — 오라클 표를 낼 때 반드시 동반한다

`2026-08-10` 신설. **25라운드에서 같은 실수를 두 번 했다.**

### 11-a. 크기정합 널 (size-matched null)

**태그로 후보를 좁힌 뒤 성능이 오르면, 그것이 태그 때문인지 후보가 줄어서인지 알 수 없다.**

> **필수 대조: 같은 크기의 무작위 후보집합(정답 강제 포함, 20시드).**

실측 (확정 210 · RRF 순서 · 20시드):

| 필터 축 | 오라클 `R@10` / `MRR@10` | 크기정합 널 | 널 승 |
|---|---|---|---|
| 특약 | .7952 / .4315 | **.8769 / .6609** | **20/20** |
| 특약×급여금 | .9381 / .6816 | **.9555 / .8338** | **20/20** |
| 특약×조항 | .9381 / .6783 | **.9560 / .8409** | **20/20** |
| 특약×조항×역할 | .9619 / .7789 | **.9738 / .9098** | **20/20** |

**전 조합에서 널이 이긴다.** 기전: 태그 셀은 같은 특약·같은 조의 **혼동 형제**를 모으고, 무작위 셀은 무관한 잡음을 모은다. 같은 개수면 후자가 쉽다.

**보조 대조군**: `특약 × 본문 앞 8자`(의미 0)가 `R@10 .9810`으로 모든 실제 축을 넘는다.

### 11-b. 규칙

| # | |
|---|---|
| 1 | **오라클 표를 단독으로 제시하지 마라.** 크기정합 널을 같은 표에 붙여라 |
| 2 | **널을 넘지 못하면 그 축은 기각이다.** "상한이 높다"는 채택 근거가 아니다 |
| 3 | BM25 색인 계열의 **길이일치 널**(`〇` 더미)과 같은 규율이다. 축이 달라도 규율은 같다 |
| 4 | 셀 수·싱글턴 비율을 성능 근거로 쓰지 마라 — **`|후보집합|`의 재진술**이다 |

### 11-c. 이 규율로 소급 기각된 것

| 축 | 기각 사유 |
|---|---|
| 태그 셀 필터 오라클 전 조합 | 크기정합 널 20/20 미달 |
| `특약×급여금` 축 | 널 미달 + 추출기가 문장 조각을 삼킴(`2조(보험금` 175건 · hapax 56.8%) |
| "유일셀 비율" 지표 | 설계서 §2.5(b) 정의(무충돌률)로는 최선 조합도 정답의 81.9%에 충돌 잔존 |
