관찰:
- **수정판 폴백은 무해화 성공**: 챔피언 기준 수정 전 −.056(유의) → 수정 후 −.011(0 포함). τ 폐기로 발화가 4/60 세션으로 급감(수정 전엔 τ=5 로 과발화)해 "오신호로 인한 손실"이 사라짐.
- 단, R@5 이득도 없음 — s30 표본에서 폴백이 실제 필요한 문항(태그 후보 <5건)이 드묾. 폴백의 가치는
  태그 검색이 진짜 빈약한 층(전수의 후보0 ~5% + 저커버 층)에서만 발생하므로 전수(329)에서 판정해야 함.
- R@10·suff@10 은 폴백 결합이 단독보다 소폭 우위(후보 폭 확대 효과) — R@5 무손실로 상위 지표를 얻는 구성.

s30 스크리닝 종합(누적): 규칙×규칙 v2 단독 .621 / +폴백수정 .618 (R@10 .686→.710) · LLM×규칙 .654 / +폴백수정 .643.
