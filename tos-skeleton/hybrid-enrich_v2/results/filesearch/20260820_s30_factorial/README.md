폴백 arm 은 vector_search/noah/0819 하네스(자동 폴백 min_n=5, τ=5.0) 그대로 사용, 태그 검색기 구성만 교체.

## 챔피언 실패 분해(만점 아닌 12/30, 세션 로그)
- multi-evidence 부분회수 6 · 검색 미노출 3 · **후보에 보였는데 제출 실패 3**
- group 단위(82건): 미노출 20% / 노출됐으나 top-5 밖 23% / 회수 57%. 검색 예산은 평균 2.1/20회만 사용.

## 발견한 버그 2건 (수정: 별도 커밋)
1. 검색 도구가 특약명을 40자로 잘라 **판본 접미사(갱신형/해약환급금 미지급형)가 소실** → 판본 4형제가 화면상 동일해 에이전트가 중복 제거하다 정답 판본을 버림. 선택 실패 3건 전부 이 패턴(2 reps 재현).
2. 폴백 병합이 페이지가 꽉 차면 **meta 항목 0개를 붙이면서 라벨만 표시** → 에이전트가 정상 결과를 빈약으로 오해, 채널 전환·예산 낭비. τ=5 는 정상 질의에도 과발화. (noah 하네스 소관 — 수정 제안 전달)

## 방향(사용자 결정): 규칙×규칙 지향
LLM 개입 없는 적재·질의로 초기 비용·재현성 우위. LLM 라우터(+.07)는 상한 참조로 유지하고, 규칙 라우터를 역색인·별칭으로 고도화해 격차 회수. 규칙×규칙+폴백은 .631 로 챔피언과 .03 차.
