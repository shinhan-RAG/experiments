- **j07549** (장해분류표 - 다리의 장해): "관절 하나의 기능에 **심한 장해**를 남긴 때"의 판정기준 중 하나로 **"인공관절이나 인공골두를 삽입한 경우"**를 명시 → 슬관절(무릎) 인공관절 수술은 장해지급률 **20%**에 해당하는 장해상태로 인정됨.
- **j00375 / j00457** ([3~100%장해형]질병장해특약 제2-2조): 질병을 직접 원인으로 장해분류표상 3%~100% 장해상태가 되면 질병장해급여금 지급 → 위 20% 장해에 해당하므로 청구 가능.
- **j00388 / j00470 / j00368**: 동 특약의 보험금 지급기준표 및 부표 준용 조항(지급금액 = 특약보험가입금액 × 해당 장해지급률).
- **j00512 / j00428** ([50%이상장해형]질병장해특약): 이 유형은 장해지급률 **50% 이상**일 때만 지급되므로, 무릎 인공관절 단독(20%)만으로는 해당 특약 청구는 불가 — 다른 부위 장해와 합산해 50% 이상이 되어야 함.
- **j06546 / j06562** (급여인공관절치환수술특약): 슬관절 포함 급여 인공관절 치환수술 자체를 보장하는 별도 특약(수술급여금, 가입 시 1회당 보험가입금액 10%) — 질병장해특약과는 별개로 가입했다면 추가 청구 가능.
