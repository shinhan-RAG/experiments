## 2. 리뷰 간 차이·추가 지적
- B: **결정론→에이전트 전이가 이미 깨짐**(qtags 결정론 +8.5pp vs 파일럿 −1.5pp) → 라우터 축은 결정론만으로 확정 금지, 결정론Δ·에이전트Δ 상관을 3~4 arm 에서 먼저 측정. **채택.**
- B: 후보 집합이 우주의 27%, 최고점 동점 5개+ 문항 37% → top-5 가 문서순(임의)으로 결정. role 슬롯이 후보 질량 19% 차지·동일 가중. `fuzzy_contains` 양방향 부분문자열 오매치. → **희소성 가중(df)·role 다운웨이트·동점 2차 키** = 설계서 2.5 "희소성 검사"의 구현(BM25 금지 위반 아님). A 도 1순위로 동일. **채택.**
- B: 라우터 실측 — 예측 270 중 적중 193(71.5%)·오지정 77·미예측 64; 층별 R@5 적중 .681 / 오지정 .147 / 미지정 .315; 적중 층 R@40 .954 → 라우터 85% 시 +12.7pp, scope 내 순위 개선 상한 +15.6pp. **채택(정량 근거).**
- B: not_answerable 10문항 제외로 오탐 지표 상실; test149 오염 대장 필요; 프롬프트가 채점 규칙(AND group)을 지시 → 절대값 과대. **채택.**
- C: **RRF 융합 목록을 에이전트 도구(`hsearch`)로 주는 arm 부재**(C3 는 에이전트가 머리로 융합). → 동료 메타 결합 시 arm 에 추가. C: 에이전트 listwise 정렬의 위치편향 상쇄(순서 셔플). A: reranker 는 설계서 개정 상신 대상. **보류(설계서 제약).**
- A/C: 라우터 개선 방법 — 급여금명·질병명→특약 역색인(태그 subject 에서 무비용), 2단계 확인, self-consistency, 저신뢰 시 미지정. **채택.**
- 상충: A 는 태그 단독 .7 "도달권", B 는 조건부(라우터 80% ∧ scope 내 .80 동시, 확률 ~60%), C 는 "낮~중". → B 의 산술을 채택하고 조건을 명시.

## 3. 수정된 계획 (변인 = Semantic Tag 만, 예산·모델·메타 고정)
0. **선결(측정 인프라)**: S1~S3 gold 재구성(strict 주지표·lenient 부지표·gap 30·라우터 비종속·SHA 동결) → `stats.py`(부호검정/BCa/Holm/MDE) → 널(shuffled_tag·constant_dummy) → 결정론↔에이전트 전이 점검(3~4 arm) → 결과 표 7-튜플·항 단위/글자예산/P@5 병기.
1. **scope 내 순위 함수**: 슬롯 df 가중·role 다운웨이트·동점 2차 키·subject 경계 일치(설계서 2.5 희소성). 결정론 → 실측.
2. **라우터 정밀도**: 급여금명→특약 역색인, 2단계 확인, self-consistency, 저신뢰 미지정. 결정론 + 실측 동시(전이 문제).
3. **태그 스키마**: subject·role LLM verbatim 추출(≤5·폐쇄코드) vs 규칙본 — S5 널과 함께.
4. **multi-evidence**: search facet(특약·조·후보수) 반환 → 재질의, 제출 조 다양성 제약. 채점 S3 수정 선결.
5. **에이전트**: A5 태그 헤더 노출(M2 재시도), 순서 셔플 대조. reps≥3, task_type 층화, 과정지표(슬롯 사용률·판독 정확도) 보고.
6. **보고 2×2**: OLD/NEW 검색기 × 스키마 — 에이전트 실측만(AND 는 결정론 무의미).
7. **결합**: 동료 메타 결합 후 RRF 도구(hsearch) arm 포함.
