### ⚠ 수치의 지위 (반드시 읽을 것)

- **train 성적**이다. 이 167문항의 실패를 보며 도구를 6회 반복 설계했으므로
  적응 편향 포함 — 봉인 test 예상치는 **.77~.79** (채움 시스템 1/4 수축 전례 적용).
- 표본 검수 12문항에서 허위 성공 0건 — 측정 자체는 정직함을 확인.
- 에이전트 모델·프롬프트가 0814 원판과 다르고 dense 채널 없음(BM25 계열만),
  1 rep, 세션당 6~10문항 배칭. **정식 등록 불가, 방향 판단용.**

## 핵심 결론 3줄

1. **평가셋이 먼저였다**: 0814의 ".705"는 제목조각·오매핑·위치채점이 섞인 값 —
   감사 gold 기준 참값 .695에서 출발해야 했다. (동일 조문 최대 60곳 반복, "지급하지 않는 사유" 277회)
2. **불완전한 신호는 필터가 아니라 점수로**: 태그 AND(−21.5pp)·concat(±0)·hard 하강(유의 열세)은
   전부 죽고, 별도채널 RRF(+2.4)·soft 가점(최고)만 살았다.
3. **다음 병목은 코드가 아니라 사람**: gold 34문항 검수 승인 → noah 하네스(dense·2 reps·문항당
   1세션·트레이스 on)에서 fill10/C′/D″ 3-arm 정식 재실험 → 사전 등록 후 봉인 test 1회 개봉.
